Component loop test

Drop your generated files into assets/loops/ next to this page and reload. Nothing here touches the portfolio — judge the loops first, apply second.

The one thing to check. Use Seam on each card. It flips between the last frame and the first frame, which is exactly where a generated loop breaks. If the object jumps, changes tooth count, or shifts brightness at that flip, the loop is dead and no amount of encoding saves it. Everything else — pretty lighting, nice materials — is secondary to that single test.
