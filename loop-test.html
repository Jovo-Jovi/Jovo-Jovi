Asset test — every image slot on the page

Put files in assets/loops/ for the hero components and assets/renders/ for the card panels, then reload. Each slot probes for an animated loop, a still, and an optional PNG frame sequence, and reports which it found. Nothing here touches the portfolio.

Seam-testing an animated WebP. A browser can't step frames inside an <img>, so the Frames mode only works if PNGs are present. To seam-test a WebP you already built, explode it back to frames first and drop them in the same folder: ffmpeg -i neural-loop.webp neural-%02d.png Frames mode will then pick them up and Seam will flip last against first. If your loop was composited over a single locked still, seam risk is low by construction — the geometry never moved.
